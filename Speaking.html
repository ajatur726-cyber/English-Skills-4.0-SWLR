Тапсырмалар

Жинақты пайдалану және GitHub Pages-қа орналастыру

Оқушыға

  1. Сыныпты, тақырыпты және жұмыс форматын таңда. Жағдаят пен тапсырманы оқы.
  2. Сөздік пен тіректерді қажетіне қарай аш. Қысқа жоспарға тек кілт сөздер жаз. Негізгі жұмыс — ауызша сөйлеу.
  3. Дайындық таймерін іске қос, кейін сөйлеу режиміне ауыс. Жұпта немесе топта таймер әр сөйлеушінің кезегіне арналған; қажетіне қарай қайта баста.
  4. Үлгіні өз жауабыңды дайындағаннан кейін қара. Ол жалғыз дұрыс жауап емес. Ұзақ сөз үлгілеріндегі ойларды жаттап алмай, өз сөзіңмен дамыт.
  5. Өзіңді бағала, рефлексияны толтыр және «Орындалды» белгісін қой. Мұғалім бағасы бөлек сақталады.

Интернетсіз ашу

index.html файлын жүктеп, браузерде аш. Негізгі мүмкіндіктер интернетсіз жұмыс істейді. Микрофон жергілікті файлда браузерге қарай шектелуі мүмкін; HTTPS арқылы ашылған бетте де рұқсат қажет. Аудионы бет жабылмай тұрып жүктеп ал.

GitHub Pages

  1. GitHub-та репозиторий құр немесе қолданыстағы репозиторийді аш.
  2. Add file → Upload files арқылы index.html файлын түбірге жүкте де, өзгерісті сақта.
  3. Settings → Pages бөлімінде жариялау көзін тармақтан таңда: Deploy from a branch. Негізгі тармақты (әдетте main) және /(root) қалтасын таңдап сақта. Интерфейс атаулары өзгеруі мүмкін.
  4. Жариялау аяқталған соң Pages бөлімінде берілген HTTPS сілтемені аш. Бұл файлда сервер, құрастыру қадамы немесе API кілті жоқ.

GitHub Pages ресми нұсқаулығы (сілтемені ашуға интернет қажет).

Жаңа тапсырма қосу

Файлды мәтіндік редакторда ашып, const TASKS = массивін тап. Бір объектіні көшіріп, бірегей id, grade, topic, topicKz және барлық мазмұн өрістерін толтыр. Формат тек Individual, Pair немесе Group болсын. Уақыт секундпен беріледі. Барлық бөлімді толтыр; үтір мен тырнақша синтаксисін сақта. Санақ пен ілгерілеу нақты деректен есептеледі. Жаңа тақырып сүзгіге автоматты қосылады.

Мұғалімге

Сөйлеу көлемі мен ұзақтығы — әдістемелік бағдар. Жинақ ресми оқу мақсаттары кодтарын алмастырмайды және нақты оқу бағдарламасына толық сәйкестікті мәлімдемейді. Оқушы тіректерді еркін пайдалана алады. Ойдан шығарылған кейіпкер атынан жауап беру барлық тапсырмада рұқсат етіледі.

Құрылымдарды бағалағанда акцентті кемшілік санамаңыз. Сөйлеудің түсініктілігіне назар аударыңыз. Аудио автоматты бағаланбайды; баллды оқушы немесе мұғалім қолмен қояды. Файлдарды жүктеу, басып шығару және деректерді тазалау алдында оқушының келісімін ескеріңіз.
